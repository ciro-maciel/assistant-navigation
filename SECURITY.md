# Security

Tabhand lets a program act in your Chrome, logged in as you, through a connection code and a tunnel server. A bug in the extension, the tunnel or the client can expose someone's accounts, so please report it privately.

**How:** open a [private security advisory](https://github.com/ciro-maciel/tabhand/security/advisories/new) on this repository. Please don't open a public issue for it.

**What helps:** the Chrome version, the steps, and what an outsider could read or do. Never attach a real connection code, cookies or page contents with private data: describe them.

You will get an answer within a week. Once a fix ships, the advisory is published with credit to you, unless you'd rather stay anonymous.

Supported: the latest release only.
